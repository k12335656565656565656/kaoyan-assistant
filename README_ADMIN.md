# 考研RAG 运营分析平台 - 管理后台

## 📊 系统介绍
本平台为考研RAG智能问答系统配套的运营分析后台，提供用户行为分析、高频问题统计、知识点分类、知识库缺口检测及PDF运营报告生成等功能，帮助运营团队掌握系统使用情况，优化知识库内容。

## 🔐 登录方式
- 访问地址：`http://111.229.102.178:8502`
- 密码：优先使用环境变量 `ADMIN_PASSWORD`；未配置时首次启动会生成随机密码并保存到用户目录的 `.kaoyan_admin_pass`，不会使用公开默认密码。

## 🧩 功能模块
1. **数据总览**：展示今日访问量、提问数、活跃用户数、问题分类率，每日提问趋势图及热门知识点分布。
2. **用户分析**：活跃用户排行榜，点击用户可查看画像（提问次数、科目偏好等）。
3. **问题分析**：高频问题排行、关键词搜索、已分类问题库（科目/章节/知识点/难度），支持CSV导出。
4. **RAG效果**：监测知识库检索质量，包括平均相似度、召回分布（需主系统接入RAG埋点）。
5. **缺口分析**（NEW）：自动检测提问中频繁出现但知识库未覆盖的问题，生成补充建议。
6. **报告中心**：一键生成专业PDF运营月报，包含趋势图、饼图、热门问题、缺口建议。
7. **系统管理**：实时日志查看、用户建议管理、数据导出。

## 🚀 使用流程
1. 管理员登录后台。
2. 在「数据总览」查看核心指标和趋势。
3. 发现某知识点提问量激增 → 去「问题分析」深入查看具体问题。
4. 若发现分类为空的高频问题 → 查看「缺口分析」，规划知识库补充。
5. 每月月初在「报告中心」生成上月运营报告，提交给团队。

## 🛠️ 部署方式
1. 克隆项目到服务器。
2. 安装依赖：`pip install streamlit pandas plotly reportlab kaleido python-dotenv`
3. 初始化数据库：`python migrate_db.py`
4. 配置 `.env`（AI_API_KEY 等）。
5. 后台启动：`nohup streamlit run admin.py --server.port 8502 > admin.log 2>&1 &`
