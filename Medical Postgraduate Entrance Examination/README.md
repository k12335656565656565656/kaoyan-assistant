# Medical Postgraduate Entrance Examination

This directory is reserved for local medical-postgraduate exam materials used by the
professional knowledge recognition system.

Suggested contents:

- public syllabus PDFs
- past paper PDFs
- OCR-ready screenshots or scanned notes
- markdown or text notes for manual import

Notes:

- Runtime will treat this folder as the default local source for the `医学考研` subject.
- Keep large or copyrighted materials out of git. `.gitignore` is configured to keep this
  README tracked while ignoring other files in this directory.
- You can override the directory with the `MEDICAL_POSTGRADUATE_ROOT` environment variable.
